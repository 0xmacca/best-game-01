Emberward — a top-down arena survival shooter. You are the last lantern warden: hold the light through ten waves of gloom, draft an upgrade between waves, break the Gloom Herald on wave 5 and unmake the Hollow King on wave 10 to bring back the dawn. Five enemy kinds, dash and nova burst, combo scoring, synthesized sound, and a victory screen with an endless mode after it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the game is static files under game/.
